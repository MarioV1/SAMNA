# docs

Material de referencia para el montaje. Son páginas HTML autocontenidas —
se abren con doble clic en cualquier navegador, sin servidor ni dependencias.

| Archivo | Qué contiene |
|---|---|
| `setup.md` | Montar el proyecto en otra computadora: qué archivo llevar, qué no copiar y dónde vive de verdad la calibración. |
| `proceso.html` | Proceso de diseño e implementación: el método, los 8 pasos con sus 27 sub‑pasos y cómo se verificó cada uno, las mediciones y los trece fallos encontrados. |
| `esquemas.html` | Cableado del MAX4466, filtro del pH y ESC de propulsión. Cada bloque en dos versiones: **mínima** para probar en el banco y **definitiva** con condensadores de desacoplo. |
| `energia.html` | Alimentación de la unidad flotante: picos de corriente, criterio para elegir la batería y el BMS, masas en estrella, condensadores y el buck de la Heltec. |
| `conexiones.html` | Inventario completo de cables y orden de montaje sobre la estructura **sin batería**, con las fuentes del banco. Qué verificar en cada paso y qué se deja deliberadamente fuera. |
| `mapa.html` | Mapa radial del sistema entero con la Heltec en el centro: sensores, actuadores, ESC, alimentación y fusible. Lo montado y lo pendiente, distinguido con el trazo. |

Estos documentos son el "cómo se cablea" y el "por qué se decidió así":
entre los cuatro cubren el montaje, la energía y el proceso de diseño
completo con sus mediciones.
